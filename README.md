<h1>🚗 Sistema de Gerenciamento de Estacionamento com Visão Computacional</h1>

<p>
Este projeto consiste no desenvolvimento de um <strong>sistema inteligente de gerenciamento de vagas de estacionamento</strong>,
implementado em uma <strong>maquete física</strong> e utilizando <strong>visão computacional</strong> para identificar automaticamente
vagas ocupadas e disponíveis.
</p>

<p>
O sistema utiliza a câmera de um <strong>celular como webcam</strong> para capturar imagens do estacionamento.
Essas imagens são processadas em tempo real utilizando <strong>Python</strong>, <strong>OpenCV</strong> e o modelo
de detecção de objetos <strong>YOLO</strong>, responsável por identificar veículos nas vagas da maquete.
</p>

<p>
A partir dessa detecção, o sistema determina o <strong>status de cada vaga</strong> (ocupada ou livre)
e disponibiliza essas informações em uma <strong>interface web</strong>, permitindo acompanhar em tempo
real a disponibilidade de vagas no estacionamento.
</p>

<h2>📌 Funcionalidades</h2>
<ul>
<li>Detecção automática de veículos nas vagas</li>
<li>Identificação de vagas ocupadas e disponíveis</li>
<li>Monitoramento em tempo real</li>
<li>Visualização das vagas através de uma interface web</li>
</ul>

<h2>🛠 Tecnologias Utilizadas</h2>
<ul>
<li>Python</li>
<li>OpenCV</li>
<li>YOLO (You Only Look Once)</li>
<li>SQLite</li>
<li>Aplicação Web</li>
</ul>

<h2>🎯 Objetivo</h2>
<p>
O objetivo do projeto é demonstrar como técnicas de <strong>visão computacional</strong> podem ser
aplicadas para automatizar o monitoramento de estacionamentos, facilitando a gestão das vagas
e melhorando a experiência dos usuários.

E para obtenção de nota e aprovação na matéria de Projeto Interdisciplinar 3 (P.I 3).
</p>
